# assets —— 需要你自己准备

这个目录默认是空的，并且被 `.gitignore` 保护。**本仓库不分发任何游戏素材。**

## 为什么是空的

明日方舟的立绘、Spine 骨骼动画、语音，著作权属于鹰角网络。把它们打进仓库或安装包再分发，
性质是传播他人的美术与音频作品——这不是"同人是否被容忍"的问题，而是会真实存在的法律风险。

所以这里的做法是：**只提供代码，素材由使用者自行准备**。这也是同人桌宠圈一直在用的方式。

## 目录约定

```
assets/
├── brand/                # 自产资源，正常提交
│   └── tray.png          # 托盘图标，npm run icon 生成
├── character/            # 角色素材，永不提交
│   ├── body.png          # 全身立绘（必需）
│   └── eyes.png          # 眼睛层（可选，有它才有眨眼）
├── audio/                # 语音，永不提交
│   └── *.ogg
└── placeholder-character.svg   # 占位图，放真素材前用它跑通
```

## body.png 的规格建议

| 项目 | 建议值 |
| --- | --- |
| 格式 | PNG，透明背景 |
| 尺寸 | 宽 240–480 px，高 470–940 px（高分辨率更清晰） |
| 构图 | 全身，脚底贴图片下边缘，水平居中 |
| 留白 | 不要留大片空白，窗口是按包围盒做鼠标命中的 |

程序用的是 `object-fit: contain` + 底部对齐，所以只要你保持"脚踩下边缘、人站中间"，
换任何尺寸的图都不会错位。

## eyes.png 怎么切

`body.png` 原样复制一份，把**眼睛以外的部分全部擦成透明**，只留眼球（含睫毛、瞳孔）。
它会叠在 body 上面，按 5.6 秒的节奏做透明度切换来模拟眨眼。

没有 eyes.png 也不影响运行，只是不会眨眼。

## 语音

放在 `assets/audio/`，命名随意。当前版本还没接播放逻辑，先把文件准备好即可。
