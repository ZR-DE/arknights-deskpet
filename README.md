# arknights-deskpet

一个安静的桌面伴侣。透明悬浮、贴边常驻、不抢焦点，会记住今天是陪你的第几天。

> **本项目只包含代码，不包含、也不分发任何游戏素材。**
> 骨骼与语音需要你自己准备，详见 [assets/README.md](assets/README.md)。

## 现在能做什么

- 无边框透明窗口，角色站在桌面上，不占任务栏
- 用 Spine 骨骼实时渲染，不是静态图也不是视频
- 待机 / 放松 / 坐下 / 睡着 四段状态按「安静了多久」自己演进，一碰就醒
- 点她、拖她、跟她说话，都会把她从休息里叫回站立并重新计时
- 鼠标只在角色轮廓内生效，其余区域直接穿透到桌面
- 拖拽移动，松手即定位
- 点她会说话，带气泡；**有语音包时是真人语音 + 原文对上字幕**
- 久不操作会主动搭话；深夜会催你去睡
- 每天第一次见面，她会报出这是第几天、连着几天
- **多套时装**：托盘菜单里直接换，选过哪套记下来，下次开机还是它
- 托盘常驻：显示/隐藏、总在最前、换装、静音、回到右下角、退出

## 快速开始

### 方式一：双击（不用装 Node）

装好依赖之后，`node_modules/electron/dist/electron.exe` 本身就是完整的运行环境，
**不需要系统里安装 Node.js**。

双击项目里的 **`启动桌宠.cmd`** 即可，命令窗口会一闪而过，然后她出现在屏幕右下角。

> 为什么是 `.cmd` 而不是 `.vbs`：`.vbs` 依赖 Windows Script Host，
> 部分系统的安全策略或安全软件会直接禁用，双击没有任何反应。
> `.cmd` 是所有 Windows 都能执行的，代价是会闪一下黑窗。
>
> 这两个脚本刻意写成**纯 ASCII + CRLF 换行**：cmd 按系统码页（中文系统是 936）
> 逐字节解析批处理文件，一旦文件是 UTF-8 却带了 `chcp 65001`，
> 中文字符的第二个字节会被当成命令的一部分，整行拆散报错。

### 方式二：命令行

```bash
npm install
npm start
```

`npm start` 走的是 `scripts/start.js`，它会清掉环境里可能存在的
`ELECTRON_RUN_AS_NODE`——这个变量会让 Electron 退化成纯 Node 运行，
主进程直接崩溃。

### 没有素材时

窗口会是空的（Spine 无法解析就没有任何东西可画），
把素材放进 `assets/character/` 再启动即可，详见 [assets/README.md](assets/README.md)。

## 换装

时装清单在 `src/shared/outfits.json`，是所有地方唯一的来源——托盘菜单按它生成，
导入脚本按它决定文件名。想加一套就加一行，然后跑：

```bash
node scripts/import-outfits.js
```

它会把 `素材/Amiya/<编号>/` 下的三件套复制到 `assets/character/`，
**同时改掉 atlas 里的页名**。这一步不能省：原始文件名带 `#`
（`build_char_002_amiya_epoque#4.png`），而 `#` 在 URL 里是 fragment 分隔符，
`pet://character/xxx#4.png` 会被截断成 `pet://character/xxx`，图集 404。

运行时换装走的是：托盘点选 → 主进程写 `settings.json` → IPC 推给渲染层 →
渲染层**先把新骨架加载好、摆好位，成功了才销毁旧的**。
反过来先销毁再加载，一旦新素材有问题，屏幕上就什么都不剩——
换装失败应该是"没换成"，不是"人没了"。

## 语音

语音包是「一个角色一个长音频」，几十分钟首尾相接，没有分隔标记。所以接语音要三步：

```
1. 切分       python scripts/segment-voice.py assets/audio/amiya.ogg \
                -o assets/audio/amiya.segments.json
2. 标注       双击 标注语音.cmd
3. 生效       重开桌宠
```

**第 1 步**只跑一次。它按音量切分：静音的地方断开，句内换气不断开。
切点靠猜不准，所以先跑一次 `--analyze` 看间隔分布——**直方图的谷底就是最佳切点**，
再据此调 `--gap`。切错了也不要紧，下一步可以手工合并。

**第 2 步**打开一个标注窗口：104 个分段一行一条，点一下放一句，把听到的字打进去。

| 操作 | 说明 |
|---|---|
| 空格 | 播放 / 停止当前段 |
| ↑ ↓ | 上下切换 |
| 字幕框里按 Enter | 存下这句，跳到下一段并自动播放 |
| 每行右侧 `⇧` | 和上一段合并（一句话被切成两半时用） |
| Ctrl+S | 保存到 `assets/audio/amiya.lines.json` |
| 留空 | 表示这句不用 |

**第 3 步**桌宠启动时读这个 JSON，点击时随机挑一句播，气泡显示的**就是这句原话**——
字幕和语音是同一份文本，不会出现「她在说一句、屏幕上是另一句」。

没标注完也能用：还没写字幕的句子不会被选中，一句话都没有时退回 `lines.js` 的原创台词。

托盘菜单里有**静音**，勾上就只显示文字——开会在共享屏幕时必须用这个。


| 命令 | 用途 |
|---|---|
| `npm run dev` | 启动并弹出独立的 DevTools 窗口 |
| `npm run spine:test` | 单独开验证窗口，打印动画名、蒙皮、包围盒 |
| `npm run voice:label` | 打开语音标注窗口（等同双击 `标注语音.cmd`） |
| 双击 `调试启动.cmd` | 不用 Node 的调试入口，日志直接显示在命令窗口里 |

## 两个实现上的必要选择

**为什么不用 `file://` 加载素材。** pixi 通过 XHR 读 `.skel` 和 `.atlas`，
而 `file://` 页面的 origin 是 `null`，请求会被 CORS 拦掉。所以主进程注册了一个
`pet://` 私有协议映射到 `assets/`，带 `corsEnabled`，同时保持 `webSecurity` 开启。

**为什么 CSP 里有 `unsafe-eval`。** pixi 7 的批渲染器用 `new Function` 生成着色器，
不放宽这一项就直接报错。这个应用不加载任何远程内容，风险面是封闭的。

**为什么气泡要挂到头骨上。** 气泡如果锚在窗口上（`left: 50%; top: 10px`），
角色一动、换动作、换表情，气泡和她的相对位置就变了。所以改成每帧取头骨
（`F_Head`）的世界坐标来定位。

但头骨落在**眼睛高度**，离可见头顶还差 150px，这个差值不能写死。也不能只在头骨
左右扫一条窄带——阿米娅的兔耳离头骨很远，窄带里只有头发，气泡就压到耳朵上了。
所以启动后把角色单独渲染成一张纹理（`renderer.extract`），扫出**每一列的最高不透明
像素**，再按气泡自己会盖住的宽度取这一段的最小值：气泡有多宽，就查它压得到的那一片，
永远贴在最上面的东西之上。换角色、换分辨率都不用重调。

顺带两个坑：绝对定位元素的可用宽度是「窗口宽 − left」，不写 `width: max-content`
的话气泡越靠右越窄，文字被迫折行、高度乱跳，看起来就像气泡自己在动；另外窗口高度
要留出 `BUBBLE_RESERVE`（110px）给气泡，否则人和气泡塞不下，气泡会被顶到脸上。

**但头骨不能无条件相信。** 加了时装之后发现：近卫那套（`sale`）的头骨 `H_Head`
换算出的世界坐标在 **-717**，直接拿来定位气泡，气泡会整个飞出窗口。同一份代码、
同一个 `toGlobal`，换一套骨架就失效——说明骨架之间的根变换不可比。
所以头骨坐标加了一道校验：**必须落在角色包围盒范围内才采信**，否则退回包围盒中点。
用头骨是为了她歪头时气泡跟着走，校验是为了这件事不至于变成"气泡消失"。

**为什么"坐下"不是随机触发的。** 姿态如果随机切，一眼就能看出是程序在动；按
「距上次互动多久」触发，才像她自己待累了。阈值定在 90 秒松下来、4 分钟坐下，
夜里 10 分钟睡着——试过 30 秒就坐，显得很急。任何一次点击或拖动都会把她叫回站立并
重置计时。姿态之间给了 0.2 秒的混合，只有点击反应压到 0.06 秒，否则拍上去她半天才动。

**姿态一变，三样东西要跟着变。** ①**命中框**：坐下后她占的地方小了一圈，不更新的话，
腿原来所在的位置还在吃鼠标，点旁边的桌面点不动；②**头顶剖面**：气泡锚点是按当前姿态
扫出来的，不重测气泡就会飘在原来头顶的高度；③**位置和大小**：`Sleep` 是躺着的，
包围盒比站着宽一倍，不缩放的话两侧直接出框（实测只剩中间一截）。
所以每次换姿态统一走一次 `resettle`：回到基准缩放 → 装不下才缩（只缩不放，站着矮
不代表该放大）→ 把底边压回窗口下沿 → 重扫剖面 → 更新命中框。
底边修正是双向的：只往上推的话，站起来时她会悬在半空回不去。

**为什么语音不切成一百个小文件。** Vorbis 每次起播要 20~50ms 解码，连着说话会听到
「咔」声，而且一百个文件名没法维护。改成整包解码一次进内存（3 分半单声道约 36MB），
按 `start / duration` 截取播放——采样级精确，跳句没有杂音。

**为什么字幕用的是游戏原文。** 语音说的是固定的话，字幕如果还是自创台词，就会出现
「嘴在说 A、屏幕写 B」的错位。所以有语音时字幕跟语音文本走，`lines.js` 的原创台词
退居为没有语音时的兜底。这也是为什么 `lines.js` 不需要为换角色重写。

运行时数据存在 Electron 的 `userData` 目录（托盘菜单「数据文件夹」可直接打开），
两个文件职责分得很开：删掉 `companion.json` 等于让她重新认识你；
删掉 `settings.json` 只是回到默认时装和默认音量，不影响你们认识多久。

代码以 MIT 发布。**MIT 只覆盖代码，不覆盖任何游戏素材。**

明日方舟的立绘、Spine 动画、语音均为鹰角网络资产。如果你 fork 这个项目，
